# Dataset

## Source
**Students Grading Dataset** from Kaggle:
https://www.kaggle.com/datasets/omerckn/students-grading-dataset

## How to Download
1. Visit the [Kaggle dataset page](https://www.kaggle.com/datasets/omerckn/students-grading-dataset)
2. Download the CSV file
3. Place it in this `data/` directory

## Specifications
- **Original Records**: 5,000+
- **After Cleaning**: 4,018
- **Features**: 23 (12 numerical, 7 categorical)
- **Target Variables**: Final_Score (regression), Grade (classification)
